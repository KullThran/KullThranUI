# KullThranUI

### Make the World of Warcraft interface your own.

[Website](https://kullthranui.com/) · [CurseForge](https://www.curseforge.com/wow/addons/kui-kullthranui) · [Wago](https://addons.wago.io/addons/kullthranui) · [Discord](https://discord.gg/cqAVWpeVvd)

KullThranUI is a modular interface addon for **World of Warcraft Retail**. It gives you room to shape your UI around the way you play, whether you want a few personal touches or a different look across your whole interface.

You choose which modules to use and how they fit together. Start with a visual style, adjust the layout and colours, and keep refining things as you play. There is no single layout you have to stick to.

Visit the [website](https://kullthranui.com/) for screenshots and a closer look at each module.

## Download and install

Get the Retail edition from [CurseForge](https://www.curseforge.com/wow/addons/kui-kullthranui), [Wago](https://addons.wago.io/addons/kullthranui), or the packaged addon attached to a [GitHub release](https://github.com/KullThran/KullThranUI/releases).

For a manual installation, close the game and extract all `KullThranUI` and `KullThranUI_*` folders from the addon package directly into your Retail client's `Interface/AddOns` folder. Keep them side by side, without an extra enclosing folder, then enable them in the character selection screen's AddOns menu.

## Getting started

Run `/installer` to open the setup wizard. Use `/kt` or `/kui` whenever you want to open the options and make further adjustments.

## Feedback and support

Join the [Discord community](https://discord.gg/cqAVWpeVvd) for help and feedback, or [open an issue](https://github.com/KullThran/KullThranUI/issues) to report a bug. Include your addon version, game version, what happened and how to reproduce it. A screenshot or Lua error helps when relevant.

## Looking for Forever?

This repository is for **Retail**. The edition adapted for **WoW Forever** is maintained separately in [KullThranUI-Forever](https://github.com/KullThran/KullThranUI-Forever).
